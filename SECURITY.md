# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability affecting the Lotus Labz website (https://lotuslabz.net) or this repository, please report it privately.

- **Email:** [jynx@lotuslabz.net](mailto:jynx@lotuslabz.net)
- **GitHub:** use the repository's private vulnerability reporting ("Report a vulnerability" on the Security tab), if available.

Please **do not** disclose security issues through public GitHub issues, pull requests, or discussions.

## What to include

- A description of the issue and the affected page, file, or URL
- Steps to reproduce, or a proof of concept
- Any relevant screenshots or logs, without including other people's personal data

## Scope

This policy covers the public Lotus Labz website and this repository. Please do not access, modify, or delete data that is not yours, and do not run denial-of-service or automated high-volume testing against the site.

Reports are reviewed on a best-effort basis. No specific response times or outcomes are guaranteed.
